# Sentinel

Sistema de gerenciamento e monitoramento desenvolvido como projeto de portfólio durante a graduação em Análise e Desenvolvimento de Sistemas.

## Tecnologias

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- React (futuro)
- Docker (futuro)
- Git e GitHub

## Objetivo

O Sentinel tem como objetivo demonstrar conhecimentos em desenvolvimento Full Stack, criando uma aplicação moderna, segura e escalável.

## Funcionalidades planejadas

- [x] Estrutura inicial do projeto
- [x] API com FastAPI
- [ ] Cadastro de usuários
- [ ] Login com JWT
- [ ] Banco de dados PostgreSQL
- [ ] Dashboard
- [ ] Controle de permissões
- [ ] Docker
- [ ] Deploy
